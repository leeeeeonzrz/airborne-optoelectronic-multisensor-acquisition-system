# 脱敏与版本边界

此版本采用“原文件保留 + 必要脱敏”的整理方式。当前导入 398 个原材料文件，其中源码（C/C++/Python/头文件）172 个，公开副本约 40,649 行源码，包含注释与空行。该统计包括已有集成组件及历史版本，不代表个人原创工作量。

对比选入文件的原始源码行，40,637 / 40,648 行保持文本相同（99.97%）；新增说明文档不计入此比例。此比例只衡量选入源码的修改幅度，不代表整个材料文件夹的收录比例。逐文件索引见 [SOURCE_INDEX.md](SOURCE_INDEX.md)。

## 本次调整

- 相机流地址从源码中的设备凭据改为环境变量，输出目录和 GNSS 配置可以独立指定。
- 个人工作空间路径改为仓库相对路径或 CMake 当前目录；Qt 6 历史配置中的安装位置改为 `QT_ROOT`。
- 界面里已有的地理位置示例归零并明确标为占位；串口配置模板不含实际设备映射。
- 完整保留 `.ui`、`.qrc`、图标、样式、仪表、ROS 包和消息定义。
- 清理 SVG 元数据中的个人导出路径，图形与作者许可保持原样。
- 第三方驱动与仪表按原文件保留许可和作者信息，不把这些集成组件归为个人原创。

## 验证范围

进行源文件保全核对、公开文件检查、Python 语法与 XML/Qt 资源引用检查。发现的原有缺项按实际记录，未以演示函数补齐。未执行完整依赖安装、目标板构建、硬件连接或性能复验；现有目录保持阶段版本特征。
