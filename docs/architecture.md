# 架构与算法

## 数据契约

Sample 携带 stream、sequence、sample_ns、arrival_ns、valid 与数值载荷。采样时间描述物理时刻，到达时间用于分析延迟。所有参与配对的采样时间必须先转入同一时钟域。

Snapshot 以参考时刻选择偏差最小的有效样本，再检查门限。缺失流独立列出。它允许选择已到达、时间晚于参考时刻的近邻样本，不宣称严格因果插值。

$$
i^*=\arg\min_i|t_i-t|,\qquad |t_{i^*}-t|\leq\tau
$$

队列容量控制资源，τ 控制配对偏差，二者不同。

## 线程与生命周期

同步器短锁内维护历史、产生值拷贝快照；锁外执行慢操作。文件线程消费有界队列，满时拒绝新项并计数。关闭后排空已入队项，再结束线程。Qt 工作对象在所属线程创建定时器，通过信号交付显示结果。

图像等大载荷宜使用独立不可变缓冲与会话索引，不直接放入数值向量。FrameDecoder 使用全新的演示帧头与长度字段，没有任何设备专有校验定义。
